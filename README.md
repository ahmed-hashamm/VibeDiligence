# VibeDiligence

VibeDiligence is a one-time-pay SaaS tool that performs automated technical due diligence on public GitHub repositories. Startup founders can submit their repo URL + 5 custom questions about their stack and receive a scored PDF report in under 10 minutes.

## Features

- **Automated Technical Analysis**: Comprehensive analysis of GitHub repositories
- **Custom Questions**: Answer 5 custom questions about your technology stack
- **Scored Reports**: Receive detailed, scored PDF reports
- **Fast Turnaround**: Get results in under 10 minutes
- **One-Time Payment**: Simple, transparent pricing with no subscriptions

## Use Cases

- **Due Diligence**: Prepare for investor meetings with technical stack analysis
- **Code Quality Assessment**: Understand your repository's technical health
- **Stack Documentation**: Get detailed insights about your technology choices
- **Investment Readiness**: Present investors with professional technical reports

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ahmed-hashamm/VibeDiligence.git

# Navigate to the project directory
cd VibeDiligence

# Install dependencies
npm install
```

### Usage

```bash
# Development
npm run dev

# Build
npm run build

# Production
npm start
```

## How It Works

1. **Submit Repository**: Provide the URL of a public GitHub repository
2. **Answer Questions**: Answer 5 custom questions about your technology stack
3. **Analysis**: VibeDiligence analyzes the repository structure, code quality, and dependencies
4. **Report Generation**: Receive a comprehensive scored PDF report
5. **Download**: Download your report for sharing with stakeholders
